Generated by `tests/integration/authorization-matrix.test.ts` (CI fails if a status changes; run `npx vitest run tests/integration/authorization-matrix.test.ts -u` after a deliberate change and review the diff).

Each endpoint is called as nobody, as each seeded role and as a Store Manager limited to Warehouse B, against fixtures in Warehouse A. Mutations use random ids or empty bodies, so allowed callers stop at validation (400), not found (404) or a business rule (422) — never 401/403. **401** = not signed in, **403** = role lacks the permission or the object is in another warehouse, **404** = not found (or hidden).
